# Fonts

The bold fonts for the widgets' text style (`widgets/shared/text_style.rs`). The regular ones
are egui's own (Ubuntu Light and Hack Regular), built into it.

| File | Font | From | License |
| --- | --- | --- | --- |
| `Ubuntu-Bold.ttf` | Ubuntu Bold 0.83, by Dalton Maag for Canonical | [google/fonts](https://github.com/google/fonts/tree/main/ufl/ubuntu) | Ubuntu Font Licence 1.0 (`LICENSE-Ubuntu-UFL.txt`) |
| `Hack-Bold.ttf` | Hack Bold 3.003, by Source Foundry, from Bitstream Vera and DejaVu | [source-foundry/Hack v3.003](https://github.com/source-foundry/Hack/releases/tag/v3.003) | MIT, with the Bitstream Vera License for the Vera parts (`LICENSE-Hack.md`) |

Both are unchanged. Credits are in `crates/app/src/credits.rs` (`MEDIA`), shown under ⚙ Settings,
"About and licenses".
